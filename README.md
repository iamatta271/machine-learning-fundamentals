# Machine Learning Fundamentals

## Project Overview

This project is part of my Machine Learning Fundamentals module. The goal of this project is to learn the basic Machine Learning workflow and build a simple classification model using Python and Scikit-learn.

For this project, I used the Iris Flower dataset to classify flowers into three species: Setosa, Versicolor, and Virginica.

## Objectives

* Understand the basic Machine Learning workflow
* Work with a real dataset
* Separate features and target variables
* Split data into training and testing sets
* Train a Machine Learning model using Scikit-learn
* Make predictions on test data
* Evaluate model performance
* Test the model with new data
* Visualize the dataset and model results

## Dataset

The project uses the built-in Iris dataset provided by Scikit-learn.

The dataset contains four features:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

The target contains three flower species:

* Setosa
* Versicolor
* Virginica

## Machine Learning Model

A **Decision Tree Classifier** was used for this project.

The dataset was divided into:

* 80% Training Data
* 20% Testing Data

## Model Performance

The model achieved:

**100% accuracy on the test dataset for the selected train-test split.**

The model was also evaluated using a confusion matrix.
